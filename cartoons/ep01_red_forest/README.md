# แสงสุดท้ายในป่าแดง ตอนที่ 1 (การ์ตูนวาดด้วยโค้ดทั้งเรื่อง)

ทำตามพรอมพ์ที่เจ้าของส่งมา (11 พ.ย. 2026): "fully code-based cartoon episode, no generative AI"
เจ้าของเลือก: ทำด้วยระบบเรา (ไม่ใช้ Higgsfield), ให้แต่งเรื่องเอง, สไตล์ใหม่โทนแดงดำแบบในโพสต์
- `episode.html` ทุกเฟรมวาดด้วย canvas (`draw(t)`), เปิดดูในเบราว์เซอร์ได้ (space = เล่น/หยุด)
- `music.py` เพลงและเสียงประกอบสังเคราะห์ด้วย numpy (ไม่มีเสียงพากย์ AI)
- `render.js` เรนเดอร์เป็น mp4: `python3 music.py m.wav && node render.js m.wav out.mp4`
- `shots.js` ภาพตัวอย่างตามเวลา: `node shots.js out/prefix 2,6,12`
เรื่อง: จิ้งจอกน้อยตะเกียงดับ → ดวงตาไล่ตาม → ทางตัน → ยักษ์ป่าแค่เอาแสง (หิ่งห้อย) มาคืน → หิ่งห้อยสว่างทั้งป่า
