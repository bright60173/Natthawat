# อาณาจักรอัสตรา: เปลวเพลิงไร้นาม — ตอนที่ 1 "เสียงเรียกจากเถ้าถ่าน" (การ์ตูน 3D สร้างจากโค้ดทั้งเรื่อง)

เจ้าของส่งแพ็กเกจส่งต่อจาก Manus (11 พ.ย. 2026): บทตอนที่ 1 (8 ฉาก), คลิปตัวอย่าง 5 วิ, พรอมพ์เดิม
"fully code-based cartoon episode, no generative AI" แล้วสั่ง "เริ่มทำตอนที่ 1 ตามเนื้อเรื่อง คลิปยาว 20 นาที++"
ผลลัพธ์: 23.5 นาที, 1920x1080 แนวนอน, ซับไทย 87 ประโยค, ดนตรี/เสียงประกอบสังเคราะห์ด้วย numpy, ยังไม่มีเสียงพากย์

## ไฟล์
- `index.html` เปิดดูในเบราว์เซอร์ได้ (`?t=วินาที`, space = เล่น/หยุด; `&gs=1` = เรนเดอร์ 3D เต็ม 1080p)
- `engine.js` ตัวละคร (เรน มีรา โกรน ยายเซรา เด็กชาย ชาวบ้าน ทหารเงา แม่ ราชันเงา หมาป่าเพลิง), ท่าทาง, ฉาก 6 แบบ
  (void ความฝัน / room / village ลูเมน / forest ป่าเงิน / hill เส้นทางภูเขา / throne), แสง, อนุภาค
- `fx.js` พลัง: เปลวเพลิงดำ, ปีกเพลิง, กรงเล็บ, หอก/แส้/กรงโลหิต, กำแพงน้ำ, เกราะผลึก, คมดาบน้ำ, ประตูเงา ฯลฯ
- `player.js` ตัวเล่นไทม์ไลน์: กล้อง, นักแสดง, ซับ, ไตเติล, เฟด/แฟลช (`draw(t)` ให้ผลเดิมทุกครั้ง)
- `story/s1.js`..`s8.js` รายการช็อตของแต่ละฉาก (บทพูดตรงตามบทต้นฉบับ; เพิ่มเฉพาะประโยคมีรา "เมืองวาเลนไม่ใช่ที่ปลอดภัย"
  และเงาสัตว์ประหลาดท้ายฉาก 8 ตามสเปกฉากถัดไปในแพ็กเกจ)
- `cues.js` ส่งออกคิวเสียง + ซับ `.srt`; `audio.py` สร้างเพลงและเสียงประกอบ; `render.js` เรนเดอร์ช่วงเวลาเป็น mp4; `shots.js` ภาพนิ่งตรวจงาน

## วิธีเรนเดอร์ (ต้องมี Node 22, Playwright Chromium, FFmpeg, python3 + numpy)
```
node cues.js out/cues.json out/astra_ep01_th.srt
python3 audio.py out/cues.json out/audio.wav
node render.js 0 138.5 out/v1.mp4        # ทีละฉาก (ดูช่วงเวลาจาก cues.json → scenes), รันขนานได้ 3 งาน
ffmpeg -f concat -safe 0 -i list.txt -i out/audio.wav -c:v copy -c:a aac -b:a 192k -shortest astra_ep01.mp4
```
ความเร็ว: เครื่องคลาวด์ไม่มีการ์ดจอ (SwiftShader) ได้ราว 3–5 เฟรม/วินาที จึงเรนเดอร์ 3D ภายในที่ 1280x720 แล้วขยายเป็น 1080p
(ซับ/ไตเติลคมชัดที่ 1080p) และทำแอนิเมชัน 12 เฟรม/วินาทีแบบอนิเมะ (on twos) ส่งออก 24 fps ตั้ง `AFPS=24` ถ้าต้องการลื่นเต็ม
