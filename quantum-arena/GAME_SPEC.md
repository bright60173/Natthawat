# GAME_SPEC — Roblox PvP: "Quantum Arena"

> สเปกนี้เขียนไว้ให้ Claude Code ใช้สร้างเกม สั่งได้เลยว่า "ทำตาม GAME_SPEC.md"
> ผลลัพธ์สุดท้ายคือไฟล์ `QuantumArena.rbxlx` ที่เปิดใน Roblox Studio ได้

---

## 1. ภาพรวม

- **แนวเกม:** PvP สู้กันได้อิสระ (Free-for-all) ไม่มีรอบ ไม่มีทีม
- **แกนหลัก:** ตอนเกิด ผู้เล่นเลือก **สายใหญ่ → สายย่อย → สกิล 3 จาก 5**
- **อุปกรณ์:** รองรับทั้งคอมและมือถือ
- **ภาษาใน UI:** ไทย (ชื่อสกิลใช้ภาษาไทยได้ ส่วนชื่อในโค้ดใช้ภาษาอังกฤษ)
- **ไม่ใช้ asset จาก Toolbox:** แผนที่และเอฟเฟกต์ทั้งหมดสร้างจาก Part, Neon, ParticleEmitter, Beam, Trail, Highlight

## 3. การควบคุม

| การกระทำ | คอม | มือถือ |
|---|---|---|
| โจมตีปกติ | คลิกซ้าย | ปุ่ม ⚔ บนจอ |
| สกิลช่อง 1 / 2 / 3 | Q / E / R | ปุ่มวงกลม 3 ปุ่มทางขวา |
| พุ่งหลบ (ทุกสาย) | Shift | ปุ่ม 💨 |
| เปิดหน้าเลือกสาย (ตอนอยู่ในจุดเกิด) | Tab | ปุ่ม ☰ มุมบน |

- ทิศของสกิลใช้ **ตำแหน่งเมาส์** บนคอม และ **ทิศที่กล้องหัน** บนมือถือ
- ใช้ `ContextActionService` เพื่อให้ปุ่มมือถือกับคีย์บอร์ดใช้ลอจิกเดียวกัน
- ตรวจอุปกรณ์จาก `UserInputService.TouchEnabled` แล้วโชว์ปุ่มบนจอเฉพาะมือถือ

## 4. ระบบหลัก

### ค่าพื้นฐาน (Config.lua)
| ค่า | จำนวน |
|---|---|
| เลือดสูงสุด | 150 |
| ความเร็วเดิน | 18 |
| พุ่งหลบ | ระยะ 25 studs, คูลดาวน์ 3 วิ, อมตะ 0.2 วิ |
| โจมตีปกติ | ตามสายย่อย (ดูตารางด้านล่าง) |
| เกิดใหม่ | 4 วิหลังตาย |
| อมตะตอนเกิด | 3 วิ (หายทันทีเมื่อโจมตี) |
| ฟื้นเลือด | 3 HP/วิ หลังไม่โดนตี 6 วิ |
| ฆ่าได้ | ฟื้นเลือด 30 HP ทันที |

### การเลือกสาย
1. ผู้เล่นเกิดในห้อง **Lobby** ที่ปลอดภัย (ตีกันไม่ได้) แล้วหน้า LoadoutUI เด้งขึ้นมาเอง
2. **ขั้น 1:** เลือกสายใหญ่ (พลัง / อาวุธ / ทักษะต่อสู้)
3. **ขั้น 2:** เลือกสายย่อย พร้อมคำอธิบายและสีประจำสาย
4. **ขั้น 3:** โชว์การ์ดสกิล 5 ใบ ให้เลือก 3 ใบ แล้วจัดลงช่อง Q/E/R ตามลำดับที่กด
5. กด "ลงสนาม" → server ตรวจว่าเลือกถูกต้อง (มีจริง, ครบ 3, ไม่ซ้ำ) → วาร์ปเข้า Arena
6. ตอนตายแล้วเกิดใหม่จะใช้ชุดเดิม ถ้าอยากเปลี่ยนให้กด Tab ตอนอยู่ใน Lobby
7. จำชุดที่เลือกล่าสุดไว้ด้วย `DataStoreService` (ห่อด้วย pcall ถ้าล้มเหลวก็ใช้ค่าเริ่มต้น)

### สถานะผิดปกติ (StatusService)
| สถานะ | ผล |
|---|---|
| Stun | ขยับและใช้สกิลไม่ได้ |
| Slow | ความเร็วลดเป็น % ที่กำหนด |
| Knockback | ใช้ `ApplyImpulse` หรือ `LinearVelocity` ชั่วคราว |
| Airborne | ลอยกลางอากาศ ใช้สกิลไม่ได้ |
| Frozen (หยุดเวลา) | Anchor ร่างไว้ + ทำให้ตัวเป็นสีเทา |
| Invisible | ตัวโปร่งใส 0.9 สำหรับคนอื่น และจะหายล่องหนเมื่อโจมตี |
| Shield | รับดาเมจแทนเลือดตามจำนวนที่กำหนด |

- Stun ซ้อนกันได้ไม่เกิน 2 วิ และหลังโดน Stun จะต้านทาน Stun 1 วิ เพื่อไม่ให้โดนล็อกจนตาย

### Kill feed และสถิติ
- `leaderstats`: Kills, Deaths, Streak
- Kill feed มุมขวาบน: "[ผู้ฆ่า] ⚡ [ชื่อสกิล] → [ผู้ตาย]" แสดง 5 บรรทัดล่าสุด หายไปใน 6 วิ
- ฆ่าติดกัน 5 / 10 ครั้ง ประกาศทั้งเซิร์ฟเวอร์ ("กำลังอาละวาด!" / "หยุดไม่อยู่!")
- คนที่ช่วยทำดาเมจภายใน 5 วิก่อนตาย นับเป็น Assist (โชว์ใน kill feed)

## 6. รูปแบบข้อมูลสกิล (SkillData)

ทุกสกิลใช้โครงเดียวกัน เพื่อให้ UI และ server อ่านได้ตรงกัน:

```lua
-- shared/SkillData/QuantumSword.lua
return {
  Id = "QuantumSword",
  Category = "Weapon",            -- "Power" | "Weapon" | "Combat"
  DisplayName = "ดาบควอนตัม",
  Color = Color3.fromHex("#00FFD5"),
  Description = "ดาบที่อยู่หลายที่ในเวลาเดียวกัน",
  Basic = { Damage = {10,10,16}, Range = 8, Cooldown = 0.35, Type = "MeleeCombo" },
  Skills = {
    {
      Id = "SuperpositionSlash",
      Name = "ฟันแยกร่าง",
      Description = "สร้างร่างควอนตัม 2 ร่างฟันพร้อมกันจาก 3 ทิศ",
      Damage = 15, Hits = 3, Cooldown = 9, Range = 10,
      Targeting = "Self",         -- "Self" | "Direction" | "Point" | "Target"
      Icon = "⚔",                 -- ใช้อีโมจิ/ตัวอักษรแทนรูป
    },
    -- ...
  },
}
```

ส่วน `SkillHandlers/QuantumSword.lua` ฝั่ง server จะ map `Id` → ฟังก์ชัน `(player, character, payload) -> ()`

## 7. เครือข่ายและการกันโกง

**RemoteEvents** (สร้างใน `ReplicatedStorage.Remotes`):
| ชื่อ | ทิศทาง | ข้อมูล |
|---|---|---|
| `SelectLoadout` | C→S | subclassId, {skillId×3} |
| `UseSkill` | C→S | slot (0=basic, 1–3, "dash"), aimPosition (Vector3) |
| `SkillFeedback` | S→C | ผลการใช้สกิล / เหตุผลที่ถูกปฏิเสธ / เวลาคูลดาวน์ |
| `PlayVFX` | S→All | effectId, ข้อมูลตำแหน่ง/ทิศ (client เป็นคนสร้างเอฟเฟกต์เอง) |
| `KillFeed` | S→All | killer, victim, skillName, assists |

**กฎฝั่ง server (บังคับ):**
- คูลดาวน์ ดาเมจ hitbox และสถานะ **คำนวณฝั่ง server เท่านั้น** client แค่ส่ง "ขอใช้สกิล + จุดที่เล็ง"
- ตรวจทุกครั้ง: ผู้เล่นยังมีชีวิต, ไม่ติด Stun, สกิลอยู่ในชุดของเขาจริง, คูลดาวน์หมดแล้ว
- จำกัด `aimPosition` ไม่ให้เกินระยะของสกิล (ถ้าเกินก็ตัดให้อยู่ในระยะ)
- จำกัดการยิง Remote ไม่เกิน 20 ครั้ง/วิ ต่อผู้เล่น
- Hitbox ใช้ `workspace:GetPartBoundsInBox` / `GetPartBoundsInRadius` / `Raycast` พร้อม `OverlapParams` ที่ไม่รวมตัวผู้ใช้สกิลเอง
- ห้ามทำดาเมจใน Lobby และห้ามทำดาเมจใส่คนที่ยังอมตะตอนเกิด

## 8. แผนที่ (MapBuilder.lua)

สร้างด้วยโค้ดตอนเริ่มเซิร์ฟเวอร์ ไม่ต้องใช้ asset:

- **Lobby:** แท่นลอยสูง (Y = 300) ขนาด 80×80 พร้อม SpawnLocation, ป้ายบอกวิธีเล่น, ประตูนีออนเดินเข้าไปเพื่อวาร์ปลงสนาม (หรือกดปุ่ม "ลงสนาม")
- **Arena:** พื้นวงกลมเส้นผ่านศูนย์กลาง 300 studs ธีม sci-fi (พื้นสีเทาเข้ม + เส้นนีออนเป็นตาราง)
  - เสาและกำแพงกำบัง 12–16 ชิ้นวางกระจายแบบสมมาตร
  - แท่นสูง 3 ระดับตรงกลาง มีทางลาดขึ้น
  - Jump pad 4 จุด (ดีดผู้เล่นขึ้นแท่นสูง)
  - จุดเกิดในสนาม 8 จุดรอบขอบ (สุ่มจุดที่ไกลจากศัตรูที่สุด)
  - กำแพงพลังงานล่องหนรอบขอบสนาม + ตกจากแมปแล้วตายทันที (Y < -50)
- **แสง:** `Lighting.ClockTime = 0`, ใส่ Atmosphere, Bloom, ColorCorrection ให้นีออนเด่น

## 9. UI

- **LoadoutUI:** การ์ดใหญ่ 3 ใบ (สายใหญ่) → การ์ดสายย่อยตามสีประจำสาย → การ์ดสกิล 5 ใบ แต่ละใบมีชื่อ, คำอธิบาย, DMG, CD กดเลือกแล้วติดเลข 1–3 ตามลำดับ, มีปุ่มย้อนกลับทุกขั้น
- **HUD:** แถบเลือดล่างกลาง (ลดแบบมี tween), ช่องสกิล 3 ช่องพร้อมตัวนับคูลดาวน์แบบวงกลมทึบ, ไอคอนพุ่งหลบ, ชื่อสายย่อยของตัวเอง
- **แถบเลือดเหนือหัว:** `BillboardGui` แสดงชื่อ + เลือด + สีสายย่อย
- **ตัวเลขดาเมจลอย:** เด้งขึ้นเหนือเป้าเมื่อเราตีโดน (เฉพาะผู้ตีเห็น)
- **มือถือ:** ปุ่มวงกลมขนาด ≥ 70px ด้านขวา ไม่ทับปุ่มกระโดดของ Roblox
- ใช้ `UIScale` + `UIAspectRatioConstraint` ให้จอขนาดต่าง ๆ แสดงผลได้ถูกต้อง
