# Quantum Arena — เกม Roblox PvP

เกมสู้กันอิสระ (Free-for-all) เลือก **สายใหญ่ → สายย่อย → สกิล 3 จาก 5** แล้วลงสนาม
มี 8 สายย่อย 40 สกิล เล่นได้ทั้งคอมและมือถือ สร้างตาม `GAME_SPEC.md`

## เปิดเกมใน Roblox Studio

1. ดาวน์โหลดไฟล์ `QuantumArena.rbxlx` ไปไว้ในคอม (Windows หรือ Mac ที่ลง Roblox Studio แล้ว)
2. ดับเบิลคลิกไฟล์ หรือเปิด Studio แล้วเลือก **File → Open from File…**
3. กด **Play (F5)** เพื่อลองเล่นคนเดียว ในสนามมี "หุ่นซ้อม" 4 ตัวไว้ลองสกิล
4. จะเปิดให้คนอื่นเล่น: **File → Publish to Roblox**

แผนที่ทั้งหมดถูกสร้างด้วยโค้ดตอนกด Play จึงเห็นพื้นที่ว่างเปล่าในโหมดแก้ไข เป็นเรื่องปกติ

### ให้เกมจำชุดสกิลล่าสุด (DataStore)

ต้อง Publish เกมก่อน แล้วเปิด **Game Settings → Security → Enable Studio Access to API Services**
ถ้าไม่เปิด เกมยังเล่นได้ปกติ แค่ใช้ชุดเริ่มต้นแทน (จะมีข้อความเตือนสีเหลืองใน Output)

## ทดสอบหลายคน

ใน Studio ไปที่แท็บ **Test → Clients and Servers** เลือก **Local Server** กับ **2 Players** แล้วกด **Start**
Studio จะเปิดหน้าต่างเซิร์ฟเวอร์ 1 อัน และผู้เล่น 2 อัน ให้ลองสู้กันได้ในเครื่องเดียว

ทดสอบปุ่มมือถือ: แท็บ **Test → Device** เลือกมือถือหรือแท็บเล็ตก่อนกด Play

## การควบคุม

| การกระทำ | คอม | มือถือ |
|---|---|---|
| โจมตีปกติ (กดค้างได้) | คลิกซ้าย | ปุ่ม ⚔ |
| สกิลช่อง 1 / 2 / 3 | Q / E / R | ปุ่มวงกลม 3 ปุ่มทางขวา |
| พุ่งหลบ | Shift | ปุ่ม 💨 |
| เปิดหน้าเลือกสาย (ใน Lobby) / กลับ Lobby (ในสนาม) | Tab | ปุ่ม ☰ |

- คอมเล็งด้วยตำแหน่งเมาส์ มือถือเล็งตามทิศที่กล้องหัน
- กลับ Lobby ได้เมื่อไม่โดนตีมาแล้ว 5 วินาที (กันหนีกลางการต่อสู้)
- ตายแล้วเกิดใหม่ในสนามด้วยชุดเดิม ถ้าจะเปลี่ยนสายให้กลับ Lobby ก่อน

## แก้โค้ดแล้ว build ใหม่

ติดตั้งเครื่องมือด้วย [Rokit](https://github.com/rojo-rbx/rokit) (`rokit install`) หรือ Aftman แล้วสั่ง

```
./build.sh
```

สคริปต์จะตรวจว่าสกิลทั้ง 40 อันมีทั้ง data และ handler แล้วสั่ง
`rojo build default.project.json -o QuantumArena.rbxlx`

ตรวจโค้ด: `selene src`

ถ้าอยากแก้โค้ดแล้วเห็นผลใน Studio ทันที ให้ใช้ `rojo serve` คู่กับปลั๊กอิน Rojo ใน Studio

## โครงสร้าง

```
src/shared/   → ReplicatedStorage.Shared      Config, Classes, SkillData (8 สาย), Remotes, VFX
src/server/   → ServerScriptService.Server    แผนที่, เกิดใหม่, เลือกสาย, สกิล, ดาเมจ, สถานะ, สถิติ
src/client/   → StarterPlayerScripts.Client   ปุ่มกด, เอฟเฟกต์, หน้าเลือกสาย, HUD, kill feed, ปุ่มมือถือ
tools/check_skills.py                         ตรวจว่า Id ของสกิลกับ handler ตรงกันทุกตัว
```

- ปรับสมดุลเกม (เลือด ความเร็ว คูลดาวน์พุ่ง ฯลฯ) ที่ `src/shared/Config.lua`
- ปรับตัวเลขสกิล (ดาเมจ คูลดาวน์ ระยะ) ที่ `src/shared/SkillData/<สาย>.lua`
- ลอจิกสกิลอยู่ที่ `src/server/SkillHandlers/<สาย>.lua` ชื่อฟังก์ชันตรงกับ `Id` ของสกิล

## การกันโกง

- client ส่งแค่ "ขอใช้สกิลช่องไหน + จุดที่เล็ง" เท่านั้น
- คูลดาวน์ ดาเมจ hitbox และสถานะทั้งหมด server คำนวณเอง
- server ตรวจทุกครั้งว่า: ยังมีชีวิต, อยู่ในสนาม, ไม่ติด Stun, สกิลอยู่ในชุดจริง, คูลดาวน์หมดแล้ว
- จุดเล็งถูกตัดให้อยู่ในระยะของสกิล และจำกัด Remote ไม่เกิน 20 ครั้ง/วินาทีต่อคน
- ตีกันใน Lobby ไม่ได้ และตีคนที่ยังอมตะตอนเกิดไม่ได้

## สถานะการตรวจสอบ

ตรวจแล้ว:
- `rojo build` ผ่าน ได้ไฟล์ `QuantumArena.rbxlx`
- `tools/check_skills.py`: สกิล 40 อัน data กับ handler ตรงกันทุกตัว
- `selene src`: 0 error, 0 warning
- ชื่อ Enum / class / service ทุกตัวในโค้ดตรงกับ API ของ Roblox (เทียบกับ API dump)

ยังไม่ได้ตรวจ:
- **ยังไม่ได้เปิดเล่นจริงใน Roblox Studio** เพราะสร้างบนเซิร์ฟเวอร์ที่ไม่มี Studio
  ครั้งแรกที่เปิดให้ดูหน้าต่าง Output ถ้ามีข้อความสีแดงให้ส่งมาแก้ได้เลย
- ความสมดุลของตัวเลขสกิล และความรู้สึกตอนเล่น (ระยะพุ่ง แรงกระเด็น ความสูง jump pad) ต้องลองเล่นแล้วปรับ

เอฟเฟกต์แรงกระแทก (เพิ่มรอบ 2, อยู่ใน `src/shared/VFX.lua`):
กล้องสั่นตามระยะ, ซูมกระตุกและจอวาบขาวดำตอนตีหนัก (ดาเมจ 30 ขึ้นไป), ขอบจอแดงตอนโดนตี,
พื้นแตกมีหินดันขึ้นและเศษกระเด็น, วงคลื่นกระแทก, ประกายไฟ, เส้นความเร็วและภาพค้างตัวละครตอนพุ่ง
ถ้ารู้สึกสั่นแรงหรือเบาไป ปรับได้ที่ `VFX.Shake` / `VFX.ShakeAt` และค่าใน `VFXController.lua`

ข้อจำกัดที่รู้อยู่แล้ว:
- ร่างปลอมของนินจาวิ่งได้แต่ไม่มีท่าเดิน (ไม่ใช้ animation asset)
- ตัวละครไม่มีท่าโจมตี ใช้เอฟเฟกต์แสงแทนทั้งหมด
