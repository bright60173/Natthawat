# คลิปตัวอย่างไวรัลที่เจ้าของช่องส่งมา (ของดีทั้งหมด เก็บไว้ศึกษาต่อ)

เจ้าของบอก: "บันทึกไว้ด้วย อะไรที่ให้ไปของดีทั้งนั้น"
ไฟล์ในโฟลเดอร์นี้เป็นสำเนาย่อขนาด (720p) ของไฟล์ต้นฉบับที่เจ้าของอัปโหลด เพื่อดูสไตล์ ไม่ใช่เพื่อเผยแพร่ซ้ำ
`sheets/` = ภาพรวมเฟรมทุก 3 วินาทีของแต่ละคลิป (ดูเร็วได้โดยไม่ต้องเปิดวิดีโอ)

แนวที่เจ้าของเลือกเป็นแนวหลักของช่อง (สลับกันอัตโนมัติในแอป):
- `guide` แบบ Sigma Lens (คลิป 06): "ถ้าเจอ...ต้องทำยังไง" สอนรับมือทีละขั้น
- `scenario` แบบ promptkub (คลิป 02-05): "ถ้าคุณอยู่ที่... ตอน..." ความเชื่อผิดหักด้วยตัวเลขจริง จบด้วยหลักคิด

## สิ่งที่นำไปใช้ในแอปแล้ว (office.html)
- `VIRAL_RULES`, `GUIDE_FORMAT`, `SCENARIO_FORMAT`, `STORY_FORMAT`
- การ์ด: stat, timer, compare, icons, bars, lesson, note, phone, plan (+ `src` ที่มาข้อมูล)
- ซับ doc + subEn, `punch` กล่องแดง, ป้าย `tag` และนาฬิกา `clock`
- ฉากวาด 2 มิติ: beach, estate, school, nightroom, aerial, street, blueprint, studio, warehouse; look `doc`
- `directorPass` บังคับสไตล์ช่อง (ลดของรก จุดเด่นเดียวต่อช็อต)

## ยังไม่ได้ทำจากคลิปเหล่านี้
- โลโก้/ชื่อช่องมุมจอ (รอเจ้าของบอกชื่อช่อง)
- กราฟเส้น/โดนัทชาร์ต (คลิป 02), ภาพผ่าดินใต้บ้าน (คลิป 05), ตัวละครสัดส่วนสมจริง (เจ้าของสั่งให้คงตัวการ์ตูนเดิม จึงไม่ทำ)
